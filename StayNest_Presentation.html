01 — Abstract
Project Overview

Abstract

Stay-nest is a comprehensive full-stack web application built using the MERN Stack (MongoDB, Express, React, Node.js) that addresses the challenges of hostel discovery and booking.

The platform integrates interactive mapping (Leaflet.js), real-time search, and Google Places API sync to deliver a premium hostel booking experience for students, travelers, and budget-conscious users.

  • Split-screen map-based search with geocoding
  • Admin panel with full CRUD & bulk data sync
  • Multi-step booking flow with user dashboard
  • Responsive glassmorphism UI design

🎯 Problem Solved

Fragmented hostel listings, unreliable data, lack of location verification, and poor user experience in existing accommodation platforms.

💡 Key Innovation

Coordinate-based listings with interactive map synchronization ensuring what users see on-screen is an accurate geographic representation.

02 — Architecture
System Design

System Architecture

Decoupled MERN Stack with three-tier design

🎨

Presentation Layer

React 18 with Vite 6.0 build engine. Handles UI rendering, routing (React Router 6), global state (Context API), and interactive maps (Leaflet.js).

React Vite Tailwind Leaflet
⚙️

Logic Layer

Node.js + Express server with RESTful API endpoints. Handles data validation, CORS, Google Places API integration, and middleware processing.

Express REST API Axios CORS
🗄️

Data Layer

MongoDB with Mongoose ODM. Stores hostel documents with geospatial indexing, booking records, and user sessions. Flexible NoSQL schema.

MongoDB Mongoose BSON GeoIndex
